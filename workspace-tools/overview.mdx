workspace-tools manages versions for JavaScript and TypeScript single-package repositories and monorepos. You record changes as changesets on your feature branches, then bump versions, write changelogs and tag releases from them. It ships as the `workspace` CLI, as Node.js bindings (`@websublime/workspace-tools`) and as Rust libraries. Use it locally or in CI/CD pipelines.

## What you can do

- Create, update, list and check changesets per branch with `workspace changeset`.
- Preview and apply version bumps, snapshots and prereleases with `workspace bump`, and create git commits, tags and pushes.
- Check for dependency upgrades, apply them, and restore backups with `workspace upgrade`.
- Audit project health (upgrades, dependencies, version consistency, breaking changes) with `workspace audit`.
- Run scripts or commands across packages, only on affected packages, or in parallel with `workspace execute`.
- Get machine-readable output with `--format json` for CI pipelines.

## Install

<CodeGroup>
```bash Shell (macOS/Linux)
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/websublime/workspace-tools/releases/download/sublime_cli_tools-v0.0.37/sublime_cli_tools-installer.sh | sh
```

```powershell PowerShell (Windows)
powershell -ExecutionPolicy ByPass -c "irm https://github.com/websublime/workspace-tools/releases/download/sublime_cli_tools-v0.0.37/sublime_cli_tools-installer.ps1 | iex"
```

```bash Cargo
cargo install sublime_cli_tools --version 0.0.37
```

```bash Node bindings
npm install @websublime/workspace-tools
```
</CodeGroup>

Prebuilt binaries are available for macOS (Apple Silicon and Intel), Linux (x86_64 GNU and musl, aarch64 GNU) and Windows (x86_64). Building from source with Cargo needs Rust 1.90.0 or later. Check the install with `workspace --version`.

## Quick example

```bash
workspace init
git checkout -b feature/new-api
workspace changeset create
# ...edit and commit...
workspace changeset update
workspace bump --dry-run
workspace bump --execute --git-tag --git-push
```
