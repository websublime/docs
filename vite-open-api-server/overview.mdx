`@websublime/vite-plugin-open-api-server` is a Vite plugin that starts a mock server from an OpenAPI spec and proxies your API path to it. It is for frontend developers who want to build against an API before the backend is ready, or without running it.

## What you can do

- Serve every operation in an OpenAPI 2.0 or 3.x spec, from a local file or a URL, in YAML or JSON.
- Get realistic responses generated from your schemas with Faker.js.
- Override responses per `operationId` with `defineHandlers()` in `*.handlers.ts` files.
- Fill the in-memory store with consistent data using `defineSeeds()` in `*.seeds.ts` files.
- Edit handlers and seeds and see them reload without restarting Vite.
- Inspect routes, the request timeline, store models and error simulations in the DevTools app, also available as a Vue DevTools tab.

## Install

The plugin supports Vite 5, 6 and 7 and needs Node.js `^20.19.0` or `>=22.12.0`.

<CodeGroup>
```bash pnpm
pnpm add -D @websublime/vite-plugin-open-api-server
```

```bash npm
npm install -D @websublime/vite-plugin-open-api-server
```

```bash yarn
yarn add -D @websublime/vite-plugin-open-api-server
```
</CodeGroup>

`vue` is a peer dependency of the package.

## Quick example

Add the plugin to `vite.config.ts`:

```typescript vite.config.ts
import { defineConfig } from 'vite';
import { openApiServer } from '@websublime/vite-plugin-open-api-server';

export default defineConfig({
  plugins: [
    openApiServer({
      spec: './openapi/petstore.yaml',
      port: 4000,
      proxyPath: '/api/v3',
      handlersDir: './mocks/handlers',
    }),
  ],
});
```

Requests to `/api/v3/*` now go to the mock server on port `4000`. To override one operation, add a handler file:

```typescript mocks/handlers/pets.handlers.ts
import { defineHandlers } from '@websublime/vite-plugin-open-api-server';

export default defineHandlers({
  getPetById: ({ req, store }) => {
    const pet = store.get('Pet', Number.parseInt(req.params.petId, 10));
    if (!pet) {
      return { type: 'status', status: 404, data: { message: 'Pet not found' } };
    }
    return { type: 'raw', data: pet };
  },
});
```
