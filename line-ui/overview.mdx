<h2 id="overview">Overview</h2>

line://ui is a set of headless UI primitives built as native Web Components with Lit, plus a CSS design system of tokens, colour palettes and themes. You style components through `::part()` and `--line-*` custom properties, so they work in any framework or in plain HTML. It is for frontend developers who want accessible building blocks. Components ship themed defaults, and you can restyle every part of them. This documentation site itself is styled with `line-tokens`, `line-colors` and `line-themes`.

<h2 id="what-you-can-do">What you can do</h2>

- Load global design tokens (typography, sizing, radii, motion, layouts and more) from `@websublime/line-tokens`, all inside one `line` cascade layer.
- Pick from 31 colour palettes in `@websublime/line-colors`, with light and dark scales.
- Theme any subtree with `data-accent="<hue>"` and `data-gray="<hue>"` through `@websublime/line-themes`.
- Use three published components: `<line-button>` (form-associated, with `default`, `primary` and `borderless` variants, a `pressed` toggle and a `loading` state), `<line-stack>` (a flex layout container) and `<line-separator>`.
- Build your own components on `LineElement` from `@websublime/line-core` and `LineMachineController` from `@websublime/line-core/machine`.
- Resolve icons from Lucide or Phosphor with the registry in `@websublime/line-icons`.

More components are on the way.

<h2 id="install">Install</h2>

Install the CSS design system, then the components you need.

<CodeGroup>

```sh bun
bun add @websublime/line-tokens @websublime/line-colors @websublime/line-themes @websublime/line-components
```

```sh npm
npm install @websublime/line-tokens @websublime/line-colors @websublime/line-themes @websublime/line-components
```

</CodeGroup>

<h2 id="quick-example">Quick example</h2>

Import the CSS once in your global stylesheet. Every hue you reference must be imported.

```css
@import '@websublime/line-tokens';
@import '@websublime/line-colors/indigo';
@import '@websublime/line-colors/slate';
@import '@websublime/line-colors/green';
@import '@websublime/line-colors/amber';
@import '@websublime/line-colors/red';
@import '@websublime/line-colors/blue';
@import '@websublime/line-themes';
```

Each component subpath registers one tag when you import it.

```js
import '@websublime/line-components/stack';
import '@websublime/line-components/button';
```

```html
<html data-accent="indigo">
  <line-stack orientation="horizontal" justify="spaceBetween" align="center" gap="3">
    <span>Title</span>
    <line-button variant="primary">Edit</line-button>
  </line-stack>
</html>
```

<h2 id="status">Status</h2>

line://ui is a work in progress. These pages document the versions published on npm:

| Package | Version |
|---|---|
| `@websublime/line-tokens` | 0.1.3 |
| `@websublime/line-colors` | 0.1.3 |
| `@websublime/line-themes` | 0.1.2 |
| `@websublime/line-schemas` | 0.1.1 |
| `@websublime/line-utils` | 0.1.0 |
| `@websublime/line-core` | 0.2.2 |
| `@websublime/line-components` | 0.2.4 |
| `@websublime/line-icons` | 0.2.0 |

- **Works:** the tokens, colours and themes; the `button`, `stack` and `separator` components; the core base classes; the Lucide and Phosphor icon resolvers.
- **Not yet:** the root entry of `@websublime/line-components` registers nothing, so you import each component by its subpath. More components are on the way.

<h2 id="contribute">Contribute</h2>

<Steps>
  <Step title="Fork and clone">
    Fork [websublime/line-ui](https://github.com/websublime/line-ui), clone it and run `bun install`. The repo needs Bun 1.4.3 or later.
  </Step>
  <Step title="Create a branch">
    Branch off `main` and make your change.
  </Step>
  <Step title="Run the checks">
    Run `bun run lint`, `bun run build` and `bun run test`, then add a changeset with `bun run changeset`.
  </Step>
  <Step title="Open a pull request">
    Push your branch and open a pull request against `main`.
  </Step>
</Steps>

<Tip>Your own CSS outside any `@layer` always beats line://ui styles, because every rule of the design system sits in the `line` layer.</Tip>
